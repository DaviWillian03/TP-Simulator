# Referências visuais — reformulação dos menus (2026-11-02)

**Limitação desta sessão:** nenhuma imagem de referência foi baixada. Lojas (Google Play, App
Store, Steam), CDNs de imagens (`play-lh.googleusercontent.com`, `*.mzstatic.com`,
`*.steamstatic.com`), sites das desenvolvedoras (`hutch.io`) e catálogos de interface
(`gameuidatabase.com`, `feedme.design`) estão fora da rede liberada. As páginas abaixo foram
confirmadas por busca; **a descrição das telas vem do conhecimento prévio desses jogos e não foi
conferida visualmente aqui**. Para conferir, liberar esses domínios e repetir a coleta.
Imagens de terceiros, se baixadas, ficam fora do repositório (direitos autorais): só este índice
é versionado.

Uso nas direções (`design/mockups/v3-*.html`): o carro em destaque e a luz de estúdio
(F1 Clash, CSR2) inspiram a **Garagem**; os cartões com imagem e a continuidade de navegação
(Real Racing 3, GT7) inspiram a **Central da equipe**; a direção **Largada** não segue um jogo:
nasce da linguagem de pôster e transmissão (diagonais, números grandes).
